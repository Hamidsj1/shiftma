# نسخهٔ ۱.۰.۵ (versionCode 6) — مجموعهٔ الگو

- **مسئله:** هر گروه (A تا D) یک الگوی جدا در فهرست بود؛ با چند الگوی چهارشیفته فهرست شلوغ و گیج‌کننده می‌شد.
- **راه‌حل:** «مجموعهٔ الگو» (`core/PatternSets.kt`): گروه‌های یک الگو یک ردیف می‌شوند با چیپ‌های رنگی (A آبی، B سبز، C نارنجی، D بنفش)؛ لمس هر چیپ همان گروه را فعال می‌کند. کارت جزئیاتِ فقط گروه فعال دیده می‌شود. «ساخت گروه‌ها» از الگوی آماده، `setName` = عنوان الگو را می‌گذارد.
- **داده / مهاجرت:** دیتابیس نسخهٔ ۳ ← ۴: فقط `ALTER TABLE shift_patterns ADD COLUMN setName TEXT NOT NULL DEFAULT ''` (`AppDb.MIGRATION_3_4`)؛ هیچ ردیفی حذف یا بازنویسی نمی‌شود. الگوهای قدیمی با نام «A»، «شیفت D»، … بدون دست‌زدن به داده خودکار یک مجموعه حساب می‌شوند. `setName` در پشتیبان و فایل الگو (`.shiftma`) هم می‌آید و پشتیبان/فایل قدیمی بدون آن خوانده می‌شود. ویرایش یک الگو `setName` آن را نگه می‌دارد.
- **تست:** `PatternSetsTest` (شامل قفل‌کردن SQL مهاجرت)، `BackupTest`. ⚠️ **قبل از انتشار حتماً روی گوشی/شبیه‌ساز با دیتابیس نسخهٔ ۱.۰.۴ (v3) نصب رو-نصب شود** و ببینید الگوها و ثبت‌های روزانه سالم‌اند؛ تست خودکار مهاجرت Room (androidTest) در این پروژه نیست.
- مجوز جدید ندارد.
