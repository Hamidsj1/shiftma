# نسخهٔ ۱.۰.۸ (versionCode 9)

موضوع: فاصله‌های صفحهٔ اول، حالت افقی، ستاره‌دهی، رنگ گروه‌ها.

- صفحهٔ اول: حذف فاصله‌های خالیِ ناشی از بخش‌های نامرئی (فاصله‌ها دستی و فقط برای بخش‌های دیده‌شده)؛ کارت «آلارم‌ها را مطمئن کنید» تک‌ردیفه؛ دکمهٔ چیدمان کوتاه‌تر؛ بخش‌ها نوار افقی.
- حالت افقی: پنل تبلیغ پنهان، نوار پایین به ستون کناری (NavigationRail)، سلول تقویم کوتاه‌تر.
- ستاره‌دهی: ۱۰ بار باز کردن، ۷ روز از نصب، حداکثر ۳ بار با فاصلهٔ ۱۴ روز؛ دکمه‌های «امتیاز می‌دهم/بعداً/دیگر نپرس»؛ دکمهٔ دائمی «امتیاز به برنامه» در درباره. بدون هیچ پاداش.
- رنگ گروه‌ها: A آبی آسمانی، B سبز، C بنفش، D صورتی؛ نشان رنگی در چیپ صفحهٔ اول.
- دکمهٔ تماس بالای پنل تبلیغ قرار می‌گیرد و از تنظیمات قابل خاموش شدن است (UiFlags، خارج از Room و پشتیبان).
- مجوز و دادهٔ کاربر: بدون تغییر؛ مهاجرت Room لازم نیست.
