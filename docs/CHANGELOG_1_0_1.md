# نسخهٔ ۱.۰.۱ (versionCode 2) — اصلاحات مرحلهٔ اول

- **روز شروع الگوها:** شروع پیش‌فرض دیگر «عدد ثابت ماه» نیست؛ از یک تاریخ مرجع (`PatternPresets.ANCHOR` = ۱۹ مهر ۱۴۰۵) با ضریب طول دوره به آخرین شروع دوره می‌رسد (`PatternPreset.defaultStart`). برای همهٔ الگوهای آماده یکسان است و کاربر هنوز می‌تواند تغییرش دهد. تست: `PatternPresetsTest` (جدول واقعی ۱ تا ۹ آبان)، `PatternFileTest`.
- **ورودی تاریخ آسان:** ارقام فارسی/عربی/لاتین؛ جداکنندهٔ `/ - . ، فاصله`؛ فقط ارقام (۱۴۰۵۰۷۱۳) خودکار به `۱۴۰۵/۰۷/۱۳` تبدیل می‌شود (`DateText.typing`). تست: `DateTextTest`.
- **تقویم:** قاب و وزن پررنگ‌تر برای روز جاری.
- **فهرست الگوها:** نشان رنگی گروه (A آبی، B سبز، C نارنجی، D بنفش) کنار نام.
- داده‌ها و Room بدون تغییر؛ مجوز جدید ندارد.
