# نسخهٔ 1.0.19 (versionCode 20)

- تنظیمات ← کاشی‌ها: بخش «به‌روزرسانی آنلاین سامانه‌ها» با تاریخ آخرین بررسی، دکمهٔ «بررسی و به‌روزرسانی الان»، فهرست آخرین تغییرها (تاریخ + چه چیزی عوض شد) و پیام روشن در صورت نبودن منبع (configFeed) یا خطای دریافت.
