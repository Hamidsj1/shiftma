# امضای ساخت‌های آزمایشی

- ساخت‌های GitHub Actions (و debug) با کلید آزمایشی ثابت `ci/test-signing.p12` امضا می‌شوند، تا هر APK آزمایشی **روی قبلی نصب شود** و دادهٔ برنامه پاک نشود (به شرط versionCode بالاتر).
- قبلاً کلید debug روی هر اجرای CI تازه ساخته می‌شد؛ امضای هر APK فرق داشت و اندروید نصب روی قبلی را رد می‌کرد.
- این کلید فقط برای آزمایش است و رمزش عمداً ساده است (در مخزن خصوصی). **هرگز برای انتشار بازار استفاده نمی‌شود**: انتشار با `keystore.properties` و کلید اصلی انجام می‌شود که داخل مخزن نمی‌آید (`*.jks`, `*.keystore`, `keystore.properties` در `.gitignore` هستند).
- نصب نسخهٔ آزمایشی روی نسخهٔ منتشرشده از بازار (کلید اصلی) ممکن نیست و برعکس؛ این طبیعی است.
- **یک‌بار** هنگام رفتن از ساخت‌های قدیمی (کلید debug تصادفی) به اولین ساخت با این کلید، حذف و نصب دوباره لازم است؛ قبلش از «پشتیبان‌گیری» یا فایل کاشی‌ها/الگوها خروجی بگیرید. از ساخت بعدی به بعد روی هم نصب می‌شود.
- هر ساخت اثرانگشت امضا را در لاگ CI چاپ می‌کند (SHA256)؛ باید بین ساخت‌ها یکسان باشد.
