# نسخهٔ ۱.۰.۴ (versionCode 5) — ویرایش و به‌روزرسانی آدرس سایت‌ها

- **ویرایش سایت در اپ:** تنظیمات ← کاشی‌ها ← «ویرایش» (عنوان، آدرس، توضیح). کلید سایت، آیکن و نام کاربری/رمز ذخیره‌شده می‌مانند (`MainVm.editSite`).
- **به‌روزرسانی از پنل (بدون وارد کردن فایل):** کانال `"sites"` در `config.json` (`core/SiteUpdates.kt`). فقط سایت‌های موجود با همان key؛ هرگز افزودن. https، بدون `@` و IP. سایتی که کاربر خودش ویرایش کرده دست‌نخورده می‌ماند (`SiteTile.edited`؛ فقط در ذخیرهٔ برنامه، نه در فایل ارسالی). اگر آدرس عوض شود آیکن کش‌شده پاک می‌شود.
- **پنل ادمین:** در برگهٔ «قفل و پنهان‌سازی بخش‌ها» بخش «به‌روزرسانی آدرس سایت‌ها» با همان قواعد؛ مستند: `docs/CONFIG_PANEL.md`.
- داده: فیلد اختیاری `edited` در JSON سایت‌ها؛ داده‌های قدیمی بدون تغییر خوانده می‌شوند (مهاجرت Room لازم نیست). تست: `SiteUpdatesTest`. مجوز جدید ندارد.
