# نسخهٔ 1.0.25 (versionCode 26)

- صفحهٔ اول: لمس طولانی روی هر کاشی نوار «سامانه‌ها» منوی ویرایش (نام، آدرس، توضیح)، حذف و «انتقال به راست/چپ» را باز می‌کند؛ روی کاشی‌های «بخش‌ها» فقط جابه‌جایی. ترتیب در همان چیدمان ذخیره‌شدهٔ صفحهٔ اول می‌ماند (حالت «چیدمان» هم مثل قبل کار می‌کند).
- یادآوری: سامانه‌ای که دستی ویرایش شود دیگر از «به‌روزرسانی آنلاین» آدرس نمی‌گیرد (ویرایش دستی اولویت دارد).
- بدون تغییر داده و مجوز.
