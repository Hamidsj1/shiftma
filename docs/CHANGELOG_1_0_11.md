# نسخهٔ ۱.۰.۱۱ (versionCode 12)

موضوع: رنگ و جای دکمهٔ تماس + نشان گروه در بقیهٔ جاها.

- دکمهٔ تماس: رنگ گرم (نارنجی `0xFFE8743B`)، کمی بالاتر (۲۶dp از پایین) و کمی نزدیک‌تر به لبهٔ چپ (۱۰dp).
- نشان رنگی گروه (A..D) در ویجت ۴×۲ و ۴×۱ (کنار نام شیفت)، زیرعنوان نوار بالای صفحهٔ شیفت، و سرستون‌های جدول چهارشیفت. رنگ‌ها با `groupColor` یکی است (`res/drawable/widget_grp_*.xml`).
- بدون تغییر داده، مجوز یا مهاجرت.
