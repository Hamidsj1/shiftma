# نسخهٔ ۱.۰.۷ (versionCode 8) — تقویم کامل بدون اسکرول

مسئله: با آوردن نوار سامانه‌ها بالای تقویم، بخشی از تقویم صفحهٔ اول پایین صفحه می‌رفت و باید اسکرول می‌شد. هدف: همهٔ تقویم در همان نمای اول دیده شود؛ بزرگ‌ترکردن تقویم خواسته نشده بود.

- **تقویم:** اندازهٔ خانه‌ها همان ۳۴dp می‌ماند؛ فقط سربرگ ماه (۳۸dp) و padding کارت کمتر شد.
- **بالای تقویم فشرده‌تر شد:** کارت بالا (padding و فاصله و آرم کوچک‌تر)، نوار سامانه‌ها بدون عنوان و با آیکن ۴۴dp و برچسب کوچک، فاصلهٔ گروه‌ها ۲۲ ← ۱۲ و حاشیهٔ بالا/پایین صفحه کمتر.
- **بدون سامانه:** به‌جای کاشی بزرگ «افزودن»، یک سطر باریک (۳۶dp) با «+ افزودن سامانه».
- داده، مهاجرت و مجوز: بدون تغییر.
