# نسخهٔ ۱.۰.۷ (versionCode 8) — تقویم بزرگ‌تر و حاشیهٔ کمتر

- **تقویم صفحهٔ اول:** خانه‌های روز از ۳۴ به ۴۲dp، سربرگ ماه کوتاه‌تر (۳۸dp) و padding کارت کمتر؛ حاشیهٔ بالا/پایین صفحه و فاصلهٔ گروه‌ها کمتر (۲۲ ← ۱۲ و ۱۴dp).
- **بدون سامانه:** به‌جای کاشی بزرگ «افزودن»، فقط یک سطر باریک (۳۶dp) با دکمهٔ «+ افزودن سامانه»؛ با وجود سامانه، نوار قبلی.
- داده، مهاجرت و مجوز: بدون تغییر.
