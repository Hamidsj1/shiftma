# ارسال انتخابی (کشوی صفحهٔ اول)

کشوی «بخش‌های دیگر» ← **ارسال انتخابی**. یک پنجرهٔ تیک‌دار باز می‌شود با فهرست‌های **الگوها**، **کاشی‌های سامانه**، **برنامه غذایی** و **مخاطبین**.
هر مورد را جدا تیک بزن (یا «همه / هیچ‌کدام»)؛ دکمهٔ ارسال تعداد انتخاب‌ها را نشان می‌دهد و تا چیزی انتخاب نشود غیرفعال است.

- فایل `.shiftma` با `type = "bundle"` ساخته می‌شود؛ کلیدهای `patterns` (آرایهٔ فایل الگو)، `tiles` (فایل کاشی‌ها)، `contacts` و `meals` همه اختیاری‌اند، ولی دست‌کم یکی لازم است.
- **برنامه غذایی:** هر مجتمعی که فایل برنامه دارد یک ردیف است (نام مجتمع، ماه و نام فایل). کلید `meals` همان آرایهٔ `complexes` فایل برنامه غذایی است (نام، برچسب ماه، نام فایل و دادهٔ base64). وقتی `meals` در فایل باشد `version` برابر ۲ است؛ بدون آن همان ۱ می‌ماند تا برنامه‌های قدیمی‌تر فایل‌های بدون برنامه غذایی را مثل قبل بخوانند. سقف حجم فایل همان ۱۵ میلیون نویسه است؛ اگر فایل‌های انتخاب‌شده بزرگ‌تر باشند پیام «حجم موارد انتخاب‌شده زیاد است» نشان داده می‌شود.
- نام کاربری و رمز سامانه‌ها هرگز در فایل نیست. بخش‌های مخفی (دفترچه، برنامه غذایی) فقط وقتی در پنجره پیشنهاد می‌شوند که در دسترس باشند.
- **دریافت:** گیرنده روی فایل می‌زند (یا از کشو «وارد کردن فایل شیفت‌ما»). ترتیب پنجره‌ها: الگوها ← کاشی‌ها (تیک‌های پیش‌فرض روشن؛ هر مورد را که نمی‌خواهد برمی‌دارد) ← برنامه غذایی (مجتمع هم‌نام به‌روز می‌شود) ← مخاطبین.
  مثلاً می‌تواند فقط یک کاشی از چند سامانه را وارد کند.
- پنجرهٔ دریافت الگو و کاشی‌ها حالا برای فایل‌های قدیمی (فقط الگو، فقط کاشی، مخاطبین + سامانه‌ها) هم تیک‌دار است.
- «جایگزینی همهٔ سامانه‌های فعلی» فقط با سامانه‌های تیک‌خورده انجام می‌شود.
- مخاطبین هنوز از «دفترچه تلفن ← مدیریت دفترچه ← ارسال فایل مخاطبین» فرستاده می‌شوند.
