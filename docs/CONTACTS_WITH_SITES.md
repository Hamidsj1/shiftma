# ارسال مخاطبین همراه سامانه‌ها

در دفترچه تلفن: «مدیریت دفترچه ← ارسال فایل مخاطبین ← همهٔ مخاطبین + سامانه‌ها».
فقط وقتی دیده می‌شود که حداقل یک سامانه (کاشی سایت) در برنامه باشد.

- فایل همان `.shiftma` از نوع `contacts` است؛ یک کلید اختیاری `tiles` (همان قالب فایل کاشی‌ها) به آن اضافه می‌شود.
  نسخه‌های قدیمی برنامه این کلید را نادیده می‌گیرند و فقط مخاطبین را وارد می‌کنند.
- بخش `sections` فقط `phonebook` است تا گیرنده بتواند دفترچه را باز کند و مخاطبین وارد شوند.
- نام کاربری و رمز سامانه‌ها هرگز در فایل نیست.
- هنگام باز کردن: اول پنجرهٔ «افزودن کاشی‌ها» (افزودن یا جایگزینی سامانه‌ها)، بعد پنجرهٔ وارد کردن مخاطبین.
  اگر گیرنده کاشی‌ها را رد کند و دفترچه برایش فعال نباشد، پیام «ابتدا دفترچه را فعال کنید» نشان داده می‌شود.
- اگر بخش `tiles` خراب باشد، مخاطبین باز هم وارد می‌شوند.
