# نسخهٔ ۱.۰.۱۴ (versionCode 15)

موضوع: بنر تبلیغ در حالت افقی و هم‌گام‌سازی آدرس کاشی‌ها از پنل.

- بنر تبلیغ دیگر در حالت افقی حذف نمی‌شود (اشتباه ۱.۰.۸)؛ به‌صورت بنر باریک و وسط‌چین (حداکثر ۲۶۰dp عرض ≈ ۴۰dp ارتفاع) نشان داده می‌شود. حالت عمودی بدون تغییر.
- پنل ادمین: سامانه‌های دارای شناسهٔ برگهٔ «کاشی‌ها» خودکار در `sites` فایل `config.json` می‌آیند تا تغییر آدرس بدون ورود فایل به گوشی برسد (جزئیات در docs/CONFIG_PANEL.md).
- بدون تغییر داده، مجوز یا مهاجرت.
