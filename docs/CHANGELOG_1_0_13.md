# نسخهٔ ۱.۰.۱۳ (versionCode 14)

موضوع: انتخاب الگوی مرحله‌به‌مرحله و بایگانی (مورد ۱۱ فهرست اصلاحات).

- «ساخت گروه‌ها» حالا دو گام است: ۱) **گروه من** (دایره‌های رنگی A–D)، ۲) **تاریخ شروع دورهٔ گروه من** (+ شرکت/سرشیفت/بخش اختیاری). همهٔ گروه‌ها ساخته می‌شوند ولی گروه من فعال می‌شود (قبلاً همیشه A).
- تاریخ شروع بقیهٔ گروه‌ها از روی ترتیب و فاصلهٔ الگو حساب می‌شود (`PatternPreset.startOf` / `aStartFromMine`، با تست).
- فهرست الگوها: دکمهٔ «بایگانی و برنامه‌های دیگر» با متن توضیحی؛ هیچ داده‌ای پاک یا جابه‌جا نمی‌شود.
- مفهوم مجموعه همان ستون `setName` نسخهٔ ۱.۰.۵ است؛ بدون تغییر Room، بدون مهاجرت جدید، بدون مجوز تازه.
