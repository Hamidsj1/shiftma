# نسخهٔ 1.0.29 (versionCode 30)

- آدرس‌های منطقه (بنر/تبلیغ، اعلان، تنظیمات راه‌دور، برنامه غذایی) همراه همهٔ فایل‌های ارسالی می‌رود، نه فقط «ارسال فایل کاشی‌ها»:
  ارسال انتخابی (کشوی صفحهٔ اول)، ارسال الگوها، فایل مخاطبین و ارسال تکی یک سامانه. اگر این گوشی آدرسی ندارد، فایل مثل قبل ساخته می‌شود.
- «ارسال الگوها» وقتی آدرسی هست فایل ارسال‌انتخابی (`bundle`) می‌سازد؛ برنامه‌های قدیمی هم آن را باز می‌کنند.
- ایمپورت تغییری نکرد: فایل بدون آدرس، آدرس فعلی گوشی را پاک نمی‌کند؛ فایل با آدرس، آن را جایگزین می‌کند. فقط آدرس‌های https مجاز (گیت‌هاب) پذیرفته می‌شوند.
- پایگاه داده و فایل پشتیبان تغییری نکرد. تست‌ها: BundleFileTest.
- آدرس‌ها برای کاربر پنهان‌اند: بستهٔ «فقط‌خوراک» (همراه فایل الگو/مخاطبین) بی‌صدا و بدون پنجرهٔ تأیید اعمال می‌شود؛ متن دربارهٔ تنظیمات راه‌دور از پنجرهٔ ورود کاشی‌ها برداشته شد؛ کادر «به‌روزرسانی آنلاین سامانه‌ها» در تنظیمات فقط وقتی منطقه وصل است دیده می‌شود (دیگر به «کلید configFeed» اشاره نمی‌کند).
