# نسخهٔ 1.0.26 (versionCode 27)

- دکمهٔ صدا هنگام آلارم/اذان: **لمس کوتاه = قطع آلارم** (مثل قبل، ولی با رها کردن دکمه)، **نگه‌داشتن = کم/زیاد کردن صدای آلارم** (دکمهٔ پایین تا صفر می‌رساند). در هر سه مسیر: سرویس دسترسی‌پذیری، صفحهٔ تمام‌صفحهٔ آلارم و نشست رسانه‌ای (در این مسیر قطع با ۴۵۰ms تأخیر است چون رها شدن دکمه دیده نمی‌شود).
