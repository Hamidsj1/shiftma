# دریافت خودکار برنامه غذایی شرکت (از گیت‌هاب)

برای نسخهٔ بازار که سه شرکت از آن استفاده می‌کنند: برنامهٔ غذایی هر ماه روی گیت‌هاب گذاشته می‌شود و برنامهٔ کاربرانِ **همان شرکت** خودش
آن را می‌گیرد و در بخش «برنامه غذایی» ذخیره می‌کند. کاربر عمومی بازار هیچ‌چیز نمی‌گیرد.

## چرا کاربر عمومی چیزی نمی‌گیرد
آدرس خوراک فقط از **فایل کاشی‌های شرکت** (کلید `mealsFeed`) می‌آید و فقط وقتی ذخیره می‌شود که کاربر خودش آن فایل کاشی را تأیید کند.
بدون آن، `pref_meal_feed` خالی است و برنامه هیچ درخواست اینترنتی برای برنامه غذایی نمی‌فرستد. فایل کاشی‌ای که کلید `mealsFeed` نداشته باشد
(و نسخه‌های قدیمی برنامه) مثل قبل کار می‌کند؛ آدرس غیرگیت‌هابی یا غیر https رد می‌شود.

## ساختار پیشنهادی ریپو
یک ریپو (مثلاً `shiftma-meals`) با یک پوشه برای هر شرکت:
```
company-a/meals.json
company-a/complex1-mehr.pdf
company-a/complex2-mehr.png
company-b/meals.json
...
```

## فایل `meals.json`
```json
{
  "enabled": true,
  "complexes": [
    { "name": "مجتمع الف", "label": "مهر ۱۴۰۵", "file": "https://raw.githubusercontent.com/USER/shiftma-meals/main/company-a/complex1-mehr.pdf" },
    { "name": "مجتمع ب",  "label": "مهر ۱۴۰۵", "file": "https://raw.githubusercontent.com/USER/shiftma-meals/main/company-a/complex2-mehr.png" }
  ]
}
```
- `name` نام مجتمع (با نام مجتمع موجود در گوشی یکی باشد، فایلش جایگزین می‌شود؛ وگرنه مجتمع تازه ساخته می‌شود).
- `file` فقط PDF یا عکس (`jpg`، `png`، `webp`، …) و حداکثر ۱۰ مگابایت؛ نوع فایل از پسوند آدرس و محتوای واقعی‌اش بررسی می‌شود.
- آدرس‌ها باید https و روی `raw.githubusercontent.com`، `github.com` (ریلیز)، `*.github.io` یا `*.githubusercontent.com` باشند. حداکثر ۲۰ مجتمع.
- برای خاموش‌کردن موقت: `"enabled": false`.
- **برای ماه بعد:** فایل تازه را با **نام تازه** بگذارید (مثلاً `complex1-aban.pdf`) و `file` و `label` را در JSON عوض کنید. برنامه فقط وقتی آدرس فایل عوض شده باشد دوباره دانلود می‌کند.

## فایل کاشی‌های شرکت
در فایل کاشی‌ها (`type = "tiles"`) دو کلید بگذارید: بخش «meals» تا بدون رمز نمایان شود و آدرس خوراک شرکت:
```json
{ "app": "shiftma", "type": "tiles", "version": 1,
  "sites": [ ... ],
  "sections": ["meals"],
  "mealsFeed": "https://raw.githubusercontent.com/USER/shiftma-meals/main/company-a/meals.json" }
```
همین کلید داخل بخش `tiles` فایل مخاطبین هم کار می‌کند. از تنظیمات هم می‌شود «ارسال فایل کاشی‌ها» زد؛ آدرس خوراکِ ذخیره‌شده همراهش می‌آید.

## رفتار در برنامه
- هنگام بازشدن برنامه و هر بار که بخش «برنامه غذایی» باز می‌شود (در بقیهٔ موارد حداکثر هر ۳ ساعت) خوراک گرفته می‌شود.
- هر مجتمعِ تازه یا تغییرکرده دانلود و جایگزین فایل قبلی می‌شود؛ مجتمع‌هایی که در خوراک نیستند دست‌نخورده می‌مانند.
- بدون اینترنت یا با فایل خراب هیچ اتفاقی نمی‌افتد و برنامهٔ قبلی می‌ماند.
- وضعیت آخرین دریافت در `files/meal_feed_state.json` است (جدا از پایگاه داده). کلید تنظیمات: `pref_meal_feed` (در پشتیبان هم می‌آید).
- مارکت‌ها: در فرم ایمنی داده بنویسید که برنامه برای کاربران سازمانی یک فایل برنامه غذایی را از گیت‌هاب می‌گیرد.
