# پنل تبلیغاتی صفحهٔ اول (اختصاصی، بدون SDK)

پنلی ثابت در پایین صفحهٔ اول که یک بنر را از فایل JSON خودتان می‌خواند. تا وقتی نشانی فایل را ندهید، پنل خاموش است
و برنامه هیچ درخواست اینترنتی برای آن نمی‌فرستد.

## روشن کردن
1. فایل `ad.json` را روی یک سرور https بگذارید (هاست، گیت‌هاب پیجز و …).
2. در `app/src/main/java/ir/shiftapp/system/AdLoader.kt` مقدار `FEED_URL` را نشانی همان فایل بگذارید.
3. برنامه را دوباره بسازید.

## قالب فایل
```json
{
  "enabled": true,
  "items": [
    { "id": "a1", "image": "https://site.ir/banners/ad1.png", "link": "https://site.ir/offer", "title": "تخفیف ویژه" }
  ]
}
```
- فقط نشانی‌های `https` پذیرفته می‌شوند؛ حداکثر ۵ تبلیغ (هر ۱۰ ثانیه جابه‌جا می‌شوند).
- اندازهٔ پیشنهادی بنر: ۱۲۸۰×۲۰۰ پیکسل (نسبت ۶٫۴ به ۱)، حداکثر ۱٫۵ مگابایت.
- برای خاموش کردن همهٔ تبلیغ‌ها بدون نسخهٔ جدید: `"enabled": false`.
- **برای عوض کردن تصویر یک تبلیغ، نام/نشانی فایل تصویر را هم عوض کنید** (تصویرها با نشانی کش می‌شوند).

## رفتار
- فایل حداکثر هر ۳ ساعت یک‌بار دوباره گرفته می‌شود؛ بدون اینترنت آخرین تبلیغ کش‌شده نشان داده می‌شود.
- روی بنر برچسب «تبلیغ» دیده می‌شود.
- وقتی پنل روشن است، یک جمله به متن «حریم خصوصی» در بخش دربارهٔ برنامه اضافه می‌شود.
- مارکت‌ها: در فرم ایمنی داده / حریم خصوصی ذکر کنید که برنامه یک تصویر و پیوند تبلیغ از اینترنت می‌گیرد.

## تبلیغ جدا برای هر محل (سونگون، سرچشمه، شهربابک، درآلو، عمومی)
- خوراک عمومی همان `FEED_URL` است و برای کاربر عمومی بازار (بدون فایل کاشی) نشان داده می‌شود.
- فایل کاشی‌های هر محل می‌تواند کلید اختیاری `adsFeed` داشته باشد (آدرس `ad.json` همان محل روی گیت‌هاب). وقتی کاربر آن فایل را تأیید می‌کند،
  پنل تبلیغ به‌جای خوراک عمومی، خوراک همان محل را نشان می‌دهد (`pref_ad_feed`؛ در پشتیبان هم می‌آید).
- فقط `https` روی `raw.githubusercontent.com`، `github.com`، `*.github.io` یا `*.githubusercontent.com` پذیرفته می‌شود؛ غیر از این نادیده گرفته می‌شود و تبلیغ عمومی می‌ماند.
- کش تبلیغ مال یک خوراک است: با عوض‌شدن خوراک (کاشی محل دیگر)، تبلیغ‌های قبلی پاک می‌شوند.
- ساختار ریپوی پیشنهادی: `ad.json` (عمومی) و پوشهٔ `sungun/`، `sarcheshmeh/`، `shahrbabak/`، `daralu/` هرکدام با `ad.json` و تصویرهای بنر خودشان.

```json
{ "app": "shiftma", "type": "tiles", "version": 1, "sites": [], "sections": ["meals"],
  "mealsFeed": "https://raw.githubusercontent.com/USER/shiftma-meals/main/sungun/meals.json",
  "adsFeed":   "https://raw.githubusercontent.com/USER/shiftma-ads/main/sungun/ad.json" }
```
